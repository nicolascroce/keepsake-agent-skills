# Keepsake Agent Skills

Give your AI agent a relational memory.

## What is this?

[Keepsake](https://keepsake.place) is a personal CRM that helps you remember every person, every interaction, every promise. This skill teaches AI agents how to use Keepsake effectively — when to log interactions, how to organize contacts, and how to build a knowledge base.

## Quick Start

1. **Create your account** at [app.keepsake.place](https://app.keepsake.place/register)
2. **Generate an API key** in Settings → API Keys
3. **Install the skill** (coming soon — for now, copy `skills/keepsake-crm/SKILL.md` to your agent's skills directory)

## What the skill teaches your agent

- 🧠 **The 3-dimension model** — Time, People, and Themes
- 📝 **Log interactions** — Calls, meetings, emails linked to the right people
- ✅ **Track follow-ups** — Tasks with due dates, recurrence, and contact links
- 📋 **Capture knowledge** — Notes as digital index cards, organized by project
- 🔍 **Search everything** — Global search for idea collisions and resurfacing connections

## Also available

- **MCP Server**: `npx -y keepsake-mcp` — 58 native tools for Claude, Cursor, and any MCP client ([npm](https://www.npmjs.com/package/keepsake-mcp))
